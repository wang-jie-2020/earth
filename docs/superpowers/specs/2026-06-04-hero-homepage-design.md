# Hero 首页设计规格（实现前确认稿）

- 日期：2026-06-04
- 状态：Approved for planning
- 页面：`examples/hero-homepage.html`（新增）
- 约束：`examples/index.html` 保持不变，仅作技术参考

## 1. 目标与范围

本规格用于定义 Hero 首屏原型实现边界，目标是在单页中提供：

1. 顶部 4 个业务指标卡片
2. 全屏 3D 地球主视觉
3. 全球点位三态交互（默认/悬停/点击）
4. 点位浮层与详情页跳转占位

本期仅做前端静态原型，不接入真实后端接口。

## 2. 核心决策（已确认）

1. 新文件从零开始写：新建 `examples/hero-homepage.html`。
2. 仅借鉴 `examples/index.html` 的渲染栈与地球参数思路，不复用旧版 hero 文件。
3. 顶部 4 指标不联动 `PROJECTS` 计算，改为 `METRICS` 常量写死。
4. `PROJECTS` 仅用于点位渲染、浮层内容和详情页参数。

## 3. 信息结构与布局

页面固定 `100vh`，不出现纵向滚动条。

1. 顶部区域：4 个并列信息块（项目总数、覆盖区域、履约率、风险数）
2. 中央区域：3D 地球占据主视觉，作为唯一主角
3. 辅助区域：左下角状态图例
4. 悬浮层：点位 hover 时出现，跟随点位屏幕投影位置

明确不做：左右业务面板、底部滚动信息条、粒子和能量弧线。

## 4. 技术架构

### 4.1 渲染栈

- `three.webgpu`
- `three.tsl`
- `OrbitControls`

### 4.2 页面模块

1. Shell/UI：顶部卡片、图例、浮层 DOM
2. Scene：相机、光照、地球与大气层
3. Markers：点位生成、状态色、交互拾取
4. Interaction：hover/click/blank click 行为
5. Animation：入场动效与常驻动效
6. Data：`METRICS` 与 `PROJECTS` 常量

## 5. 数据模型

### 5.1 固定指标（写死）

使用 `METRICS` 常量作为顶部卡片唯一数据源：

- `totalProjects`
- `coverageRegions`
- `deliveryRate`
- `riskCount`

### 5.2 点位数据（业务 mock）

使用 `PROJECTS` 数组，每项包含：

- `name`
- `country`
- `region`
- `lat`
- `lon`
- `type`
- `desc`
- `status`

其中 `status` 映射三类视觉状态（运营中/在建/异常或风险观察）。

## 6. 交互流程

1. 页面加载：进入全局视角并开始慢速自转
2. Hover 点位：点位高亮 + 浮层显示名称/国家地区/类型/描述
3. 移出点位：浮层关闭
4. Click 点位：打开详情页占位（query 参数方式）
5. Click 空白：关闭浮层并清理选中态

## 7. 动效与视觉规范

### 7.1 入场动效

1. 顶部卡片依次淡入
2. 地球透明度和缩放渐入
3. 点位按序亮起

### 7.2 常驻动效

1. 地球持续缓慢自转
2. 点位轻呼吸闪烁
3. 浮层淡入淡出

### 7.3 风格边界

- 深色、稳重、科技感
- 允许轻量网格或弱背景层次
- 不使用粒子、能量弧线、夸张光晕

## 8. 浮层跟随与可见性策略

每帧执行以下逻辑：

1. 将目标点位世界坐标投影到屏幕坐标
2. 用投影结果更新浮层 `left/top`
3. 当点位位于地球背面或超出可视范围时隐藏浮层

目标：避免旋转时浮层“漂移”或“悬空错位”。

## 9. 错误处理与降级

1. 贴图加载失败：回退到纯色材质地球，不让页面空白
2. `PROJECTS` 为空：地球与 UI 仍可渲染，点位为空，不抛阻塞错误
3. 浮层字段缺失：显示占位文案，避免空值导致脚本异常

## 10. 测试与验收口径

### 10.1 功能

1. `examples/hero-homepage.html` 单屏展示，无纵向滚动
2. 顶部 4 指标显示正常，来源为 `METRICS`
3. 点位三态完整，hover 浮层与 click 行为正确
4. 点击空白可关闭浮层

### 10.2 视觉与交互

1. 地球为视觉中心，无左右面板
2. 文字与图层不互相遮挡，可读性稳定
3. 浮层随地球旋转保持可接受跟随效果，背面自动隐藏

### 10.3 性能与分辨率

在以下桌面分辨率下布局不崩、无明显卡顿：

- 1920x1080
- 1440x900
- 1366x768

## 11. 非目标（本期不做）

1. 真实 API 接入与权限控制
2. 点位聚合、分层渲染策略
3. 多语言切换
4. 完整详情业务页（仅占位跳转）
